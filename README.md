# MyDesk Next

本版本包含真实 rToken 行情适配、关注列表、研究卡片与可选 AI 转译。

## 启动

Windows 便携版：完整解压 ZIP，先连接 VPN，再双击本目录的「启动 MyDesk.exe」。
它带有 MyDesk 自己的图标；`启动MyDesk.cmd` 仍作为兼容入口保留。
便携版包含运行环境与依赖，不需要另装 Node.js 或执行安装命令。
启动器会打开连接检查页，分别确认真实 K 线与 MCP 工具目录；检测成功后点「进入研究工作台」。
请保持启动窗口运行（可最小化）。

源码版：需要 Node.js 24.16 或更高版本，在本目录执行：

```sh
npm ci --ignore-scripts
npm start
```

通常打开 http://127.0.0.1:4173/startup 。默认端口被旧版本或其他程序占用时，会选择附近的空闲端口并自动打开，不会结束已有程序。
同一文件夹的当前版本已在运行时直接复用。端口不同会使用不同的浏览器存储空间，原端口的数据不会被删除；重要记录请先导出。

直接双击 MyDesk-next.html 只能打开离线演示。浏览器不能从 HTML 文件启动本机 Node 服务。

## VPN 与连接

默认自动检测系统 HTTP 代理、环境变量代理（含 ALL_PROXY）、VPN 全局/TUN 隧道。
这些线路失败时，再检查常见本地 HTTP/SOCKS5 端口及系统代理进程的其他监听端口。
Hub 与 MCP 分别选择通过真实接口验证的线路，保留 TLS 证书验证。
支持的环境变量：MYDESK_PROXY_URL=auto（默认），或一个明确的 HTTP/HTTPS/SOCKS 代理地址。
MYDESK_PROXY_DISCOVERY=0 可禁用附加本地端口探测（第 1 层：按进程名识别代理客户端 + 常见代理端口）。
MYDESK_PROXY_WIDE_SCAN=0 可禁用全端口兜底扫描（第 2 层，只有前两层全灭时才会启动）。
连接实在连不上时，运行 `诊断连接.cmd`（或 `npm run doctor`）会落盘一份《诊断报告-*.txt》，直接发给开发者即可。

若自动检测失败，在连接检查页填写 VPN 客户端显示的实际 HTTP / SOCKS5 代理地址并重试。
连接检查页也支持 VPN 换节点或换端口后重新识别，无须修改代码或重启。
手动填写只在本次启动有效；要永久指定可在 .env 中设置 MYDESK_PROXY_URL。
浏览器扩展类代理通常不代理 Node 程序；需要系统代理、全局隧道或可用的本机代理端口。
开启 VPN 本身不能保证所选节点能访问两个 Bitget 域名，以连接检查结果为准。
公开行情不需要账号 Key；可选的 AI 转译功能仍需另配模型服务。

## 本次更新

- 修复 K 线「断成一截一截」：断线判定原来按标称间隔的 1.5 倍算，而 rToken 日线
  **天生缺周六**（相邻两根相差 48h）、长周末会到 72h，于是 300 根日K里有 35 处被剪断，
  收盘线、均线和填充区在每个周末都断一次。改成按这套数据自己的「正常间隔」（众数）
  的 4 倍判定，并加一条「至少空满一整天」的底线 —— 1 小时线里最大的空档实测才 8h，
  只按 4 倍算阈值是 4h，那些几小时的洞会把 MA5 / MA10 / MA20 各切成三段。
  真的缺了一大段时仍然断开，并画一条竖直虚线标出来，图例同步出现「缺数据」，
  无障碍名称里也会写明阈值（例如「空档超过 24 小时」）。
  蜡烛实体宽度从槽宽的 0.55 提到 0.72，不再是一排梳子。
- 新增「删除判断」，并且**随时能撤销**：
  - 入口两处：列表行尾的垃圾桶（点它会先打开这张卡、底部直接落在确认态，让你看清删的是哪一张），
    或回看弹窗底部的「删除这张判断」。
  - **批量**：每行都有勾选框，勾选后表格上方浮出操作条，二次确认后一次删掉；
    勾选框在可点击的行里面，点它不会顺带打开那张卡。
  - **删除只是移进回收站**，不是真删。删完的提示条里有「撤销」（12 秒），整批一次拿回来；
    「选标的与设置」页还有「最近删除」面板，错过提示条也能逐条恢复或清空。
    回收站最多留 20 条，满了会挤掉最旧的，日志里会写明。
  - **不可逆的都要问一次**：批量删除、逐条「彻底删除」、整栏「清空回收站」，
    都是先原地换成确认条，再点一次才执行 —— 这一层没有撤销。
  - 复盘、承接关系、弹过的裁决在删除时就清掉（否则导出会带一串指不到卡片的孤儿），
    但清之前原样存进回收站的记录里，撤销或恢复时再放回去 —— 两头都不丢。
  - 同一请求重新保存不会被旧的幂等记录挡住；恢复时幂等记录也补回来，不会存出重复卡。
- 修复 Meta 删除、删除后图表不同步、清空关注列表被恢复的问题。
- 保留取消关注标的的历史研究；缺失价格显示为空。
- 通过官方 Agent Hub SDK 接入 rToken 行情。
- 接入独立的 Bitget MCP Server，用于参考资料工具。
- rMETA 行情仅对应 RMETAUSDT，不混用 META 原股价格。

接口、配置、代理和验证状态见 [后端接入说明.md](./后端接入说明.md)。

## 文件

- `src/app.js`：界面、关注列表、研究记录。
- `src/engine.js`：已收盘日线、冻结快照、条件与复核。
- `src/live.js`：rToken 行情转换、Agent Hub 后端入口。
- `src/translate.js`：可选 AI 转译与规则降级。
- `backend/bitget.cjs`：Agent Hub SDK 与远程 MCP 客户端。
- `backend/network.cjs`：代理与网络请求设置。
- `server.cjs`：本机 HTTP 服务与后端路由。
- `.env.example`：可选配置样例。
- `02-多想一步-LLM约束-v2.4.md`：判断转译、写卡时「说清楚」与后续行情进展的当前 LLM 契约。
- `启动 MyDesk.exe`：带品牌图标的 Windows 启动入口；`assets/mydesk.ico` 是多尺寸系统图标。
